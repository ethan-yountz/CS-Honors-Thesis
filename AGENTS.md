# Agent Guidelines

## Commits and Authorship

- Never take credit as a co-author. Do not add `Co-authored-by:` trailers, "Generated with" footers, or any other attribution to yourself in commits, pull requests, or code.

## Testing and Verification

- Never write tests. Do not create unit tests, integration tests, test files, or test fixtures.
- Verify changes end to end instead: run the actual code and inspect its real outputs to confirm it behaves correctly.
